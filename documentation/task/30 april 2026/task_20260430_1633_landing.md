## 📝 NOTES UNTUK JUNIOR DEVELOPER

### 💡 **Tips Penting:**
1. **Focus di UX dulu, bukan perfection**
2. **Gunakan Tailwind components yang sudah ada**
3. **Test di mobile dulu, baru desktop**
4. **Jangan takut pakai dummy data dulu**
5. **Validasi form di frontend + backend**

### ⚠️ **Common Mistakes to Avoid:**
1. **Over-engineering di awal**
2. **Lupa responsive design**
3. **Skip form validation**
4. **Hardcode semua data**
5. **Lupa error handling**
